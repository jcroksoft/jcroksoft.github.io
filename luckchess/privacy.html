4. 온라인 대전에서 처리되는 정보Information processed for online play

온라인 대전, 친구 대전, 보스 토벌전은 토스 버전과 Android 버전 모두 개발사가 운영하는 같은 게임 서버를 거칩니다. 그래서 두 버전의 이용자가 서로 만날 수 있습니다. 서버는 상대를 찾아 주고, 주사위를 굴려 전투를 공정하게 판정하고, 두는 수를 참가자에게 전달합니다. 온라인 메뉴를 쓰지 않으면 서버와 통신하지 않습니다. Online matches, friend matches, and boss raids in both the Toss and Android versions go through the same game server we operate, so players of the two versions can meet each other. The server finds opponents, rolls the dice so battles are judged fairly, and relays moves to the players. If you don't use the online menus, the Game does not contact the server.
