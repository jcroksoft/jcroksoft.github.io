아래 정보는 앱이 정상 동작하기 위해 기기 내부 저장소에만 보관되며, 외부로 전송되지 않습니다. The following is kept only in your device's local storage so the App can work, and is never transmitted:

  • 음악 목록 색인 — 곡 제목, 아티스트, 앨범, 재생 시간, 파일 경로A music index — track title, artist, album, duration, and file path

  • 앱 설정 — 선택한 테마, 언어 설정, 취침 종료 기본값App settings — selected theme, language preference, and sleep timer defaults
  • 재생목록과 즐겨찾기 — 이용자가 직접 만든 목록의 이름과 곡 구성Playlists and favorites — the names and contents of lists you create yourself
  • 직접 입력하거나 수정한 가사, 가사 검색용으로 따로 지정한 제목·아티스트명Lyrics you typed or edited, and any title or artist you set specifically for lyrics search

앱을 삭제하면 이 정보는 기기에서 함께 삭제됩니다. Uninstalling the App deletes all of this from your device.

  • 곡 정보 수정 — 이용자가 수정한 제목, 아티스트, 썸네일을 해당 음악 파일에 저장합니다. 시스템이 파일 변경 허용을 묻고, 허용하지 않으면 앱 안에서만 보이는 표시로 대체합니다.Edit track info — saves the title, artist, or thumbnail you entered into the music file itself.   • 벨소리 설정 — 선택한 곡을 기기의 기본 벨소리로 지정합니다. 시스템의 ‘설정 변경 허용’이 필요합니다.Set as ringtone — sets the chosen track as your device's default ringtone. Requires Android's “Modify system settings” permission.

  • 배터리 사용량 제한 해제 — 장시간 재생이 중단되지 않도록 시스템 설정 화면을 열어 안내만 합니다. 앱이 직접 변경하지 않습니다.Battery usage limit — only opens the system settings screen so long playback is not force-stopped. The App does not change the setting itself.

4. 광고를 통해 처리되는 정보Information processed for advertising

앱은 무료로 제공되며 화면 일부에 배너 광고를 표시합니다. 전면 광고, 앱 시작 광고, 보상형 광고는 사용하지 않습니다. 광고는 AppLovin MAX를 통해 제공되며, 광고 요청 시 AppLovin 및 연결된 광고 네트워크가 다음 정보를 처리할 수 있습니다. The App is free and shows banner ads in parts of the interface. We do not use interstitial, app-open, or rewarded ads. Ads are delivered through AppLovin MAX. When an ad is requested, AppLovin and its mediated ad networks may process:

  • 광고 식별자 — Android 광고 ID(AAID) 또는 iOS 광고 식별자(IDFA / IDFV)Advertising identifiers — the Android Advertising ID (AAID) or the iOS IDFA / IDFV
  • 기기 정보 — 기기 모델, 운영체제 버전, 화면 크기, 언어, 국가, 시간대Device information — device model, OS version, screen size, language, country, and time zone
  • 네트워크 정보 — IP 주소, 연결 종류. IP 주소로부터 대략적인 지역이 추정될 수 있습니다.Network information — IP address and connection type. An approximate region may be inferred from the IP address.
  • 광고 상호작용 정보 — 광고 노출, 클릭, 광고 관련 앱 이벤트Ad interaction data — impressions, clicks, and ad-related app events

이 정보는 광고 게재, 광고 빈도 조절, 부정 클릭 방지, 광고 성과 측정을 위해 사용됩니다. 개발사는 이 정보를 직접 수집하거나 별도로 보관하지 않으며, 집계된 광고 성과 통계만 AppLovin 대시보드를 통해 확인합니다. This is used to serve ads, control ad frequency, prevent fraud, and measure ad performance. We do not collect or separately store this data ourselves; we only see aggregated performance statistics in the AppLovin dashboard.

동의가 필요한 지역 — 유럽경제지역(EEA), 영국, 스위스 등 사전 동의가 필요한 지역에서는 맞춤형 광고에 대한 동의 절차를 거친 뒤에만 해당 목적의 처리가 이루어집니다. 동의는 앱 설정의 개인정보 관련 항목에서 다시 변경할 수 있습니다. Where consent is required — in the EEA, the UK, Switzerland, and other regions requiring prior consent, processing for personalized advertising only takes place after you have given consent. You can change your choice again from the privacy option in the App's Settings.

AppLovin의 개인정보 처리에 대한 자세한 내용은 AppLovin 개인정보처리방침을 참고해 주세요. For details on AppLovin's own processing, see the AppLovin Privacy Policy.

5. 온라인 가사 검색Online lyrics lookup

앱은 음원에 내장된 가사와 기기의 LRC·TXT 파일을 먼저 찾습니다. 그래도 가사를 찾지 못했고 이용자가 온라인 검색을 사용하는 경우에만, 곡 제목과 아티스트명 등 검색에 필요한 최소한의 정보가 가사 제공처로 전송됩니다. The App first looks for lyrics embedded in the audio file and for matching .lrc or .txt files on your device. Only if none are found and you use online lookup does the App send the minimum information needed to search — such as the track title and artist name — to the lyrics provider.

  • 음악 파일 자체는 전송되지 않습니다.The audio file itself is never sent.
  • 광고 식별자나 이용자를 식별할 수 있는 정보는 함께 전송하지 않습니다.No advertising identifier or user-identifying information is sent with the query.
  • 전송 과정에서 제공처는 접속 IP 주소를 확인할 수 있습니다.As with any network request, the provider can see the IP address of the connection.
  • 가져온 가사는 앱 전용 저장소에 캐시되며, 앱 삭제 시 함께 삭제됩니다.Retrieved lyrics are cached in app-private storage and removed when the App is uninstalled.
